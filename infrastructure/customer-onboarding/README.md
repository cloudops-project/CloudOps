# Customer Onboarding Templates

The API generates customer trust and read-only permission guidance described in [AWS onboarding](../../docs/architecture/aws-account-onboarding.md). Cross-account access uses the CloudFix workload identity, STS role assumption, and a per-connection External ID; customer access keys are never requested or stored.

This legacy directory contains no deployable onboarding template. Generated guidance still requires customer review and live sandbox validation before use.
