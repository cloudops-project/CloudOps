# CloudOps Code of Conduct

## Purpose and audience

This code applies to contributors, reviewers, stakeholders, and project spaces. Cloud security work benefits from candid disagreement conducted respectfully.

## Expected behavior

Be inclusive, specific, and evidence-led. Critique decisions rather than people; protect confidential customer and vulnerability information; disclose conflicts; credit contributions; respect accessibility needs and time zones; and escalate security concerns privately. Harassment, discrimination, threats, doxxing, credential sharing, and retaliation are unacceptable.

## Reporting and enforcement

Report conduct concerns privately to the project lead or a designated backup who is not involved in the complaint. Maintainers will limit disclosure, investigate proportionately, document decisions, and may warn, restrict, or remove participants. The team must designate named contacts and an appeal path before external contributors are invited.
