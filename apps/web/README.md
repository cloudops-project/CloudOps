## Purpose and audience

Future frontend contributors will use this area for the React/TypeScript/Vite application after approval.

The planned stack is Material UI, TanStack Query, React Router, strict TypeScript, and Zod or equivalent. Features follow the [information architecture](../../docs/design/information-architecture.md) and [design system](../../docs/design/design-system.md). Visual components do not make direct API calls, and client visibility never substitutes for server authorization.

No package manager, component, dependency, or build configuration exists in Stage 0. Open decision: testing/linting tools and exact feature layout.
