# Shared Types — Stage 0 Placeholder

## Purpose and audience

Future API/web maintainers may use this area for deliberately stable generated or language-neutral contracts that truly cross application boundaries.

Shared code must remain minimal and cannot become a generic utilities package or bypass feature ownership. API OpenAPI generation and versioning are candidates; domain internals and authorization logic are not. Changes require both producer and consumer review.

No package manager, schema generator, dependency, or source file exists in Stage 0. The need for this package must be validated before creation.
